# SQLCipher (AES-256 at-rest encryption). The DB layer auto-detects the driver:
#   Linux x86_64 / aarch64 -> prebuilt wheel, no system deps.
#   Windows / macOS        -> `sqlcipher3` builds against a system SQLCipher
#                             (brew install sqlcipher / vcpkg install sqlcipher).
#   Android / iOS          -> no SQLCipher wheel for Flet's mobile runtime; the app uses
#                             platform-protected SQLite + a Keystore/Keychain device key.
#                             Packaged builds get their drivers from [tool.flet.<target>]
#                             in pyproject.toml, not from this file.
sqlcipher3-binary>=0.5; sys_platform == "linux"
sqlcipher3>=0.5; sys_platform == "darwin" or sys_platform == "win32"

# NOTE: pysqlcipher3 is also supported as a fallback driver, but it is
# unmaintained and not listed here on purpose.
